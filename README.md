## 🚀 Quick Start

### Prerequisites

- 🌐 Modern web browser (Chrome, Firefox, Safari, Edge)
- 📝 Text editor (VS Code recommended)
- 🔧 Git (for cloning)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/nishantxcode/Nishant-Portfolio-Website.git
   ```

2. **Navigate to project directory**
   ```bash
   cd Nishant-Portfolio-Website
   ```

3. **Open in browser**
   ```bash
   # Option 1: Direct file opening
   open index.html
   
   # Option 2: Using Python HTTP server
   python -m http.server 8000
   
   # Option 3: Using Node.js http-server
   npx http-server
   ```

4. **Start developing**
   - Open `index.html` in your browser
   - Make changes to HTML, CSS, or JS files
   - Refresh browser to see changes

## 🎨 Customization

### 🖼️ **Updating Profile Information**
- Edit personal details in `index.html`
- Replace `assets/images/my-avatar.png` with your photo
- Update contact information and social links

### 🎯 **Adding Projects**
- Add project images to `assets/images/`
- Update project section in `index.html`
- Modify project data in `script.js` if needed

### 🎨 **Styling Changes**
- Customize colors, fonts, and layout in `assets/css/style.css`
- Modify animations and transitions
- Update responsive breakpoints
